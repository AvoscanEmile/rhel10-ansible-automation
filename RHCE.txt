0. Setup VSCode and the Ansible Developer Container. 
1. Clone the Github Repo. 
2. Create inventory with groups (inventory.ini. Use ansible-navigator to validate).
3. Setup configuration files (ansible.cfg and ansible-navigator.yml. Use ansible navigator to initialize and validate them).
4. Setup Ansible Vault with the secret variables you want to store.
5. Distribution of public keys for SSH key-based authentication, at the same time turn off password based authentication.
6. Configure Repositories
7. Reach the desired generated state using Role-Based playbooks, based on the groups inside inventory.ini, and the actual RHEL official roles.
8. Commit and push to the Github repo.
9. Delete your copy then repeat. 

Make the habit of solving every mockup test with only the provided docs instead of exterior help.
